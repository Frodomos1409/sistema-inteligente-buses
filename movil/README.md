# Movil

Producto movil del sistema inteligente para buses. Segun el Stack A del curso, esta carpeta debe contener la app Flutter que consume la API REST publicada por `web/`.

## Comandos planeados

```bash
flutter pub get
flutter test
flutter build apk --release
```

El APK release se debe copiar a:

```text
movil/releases/app-v0.1.0-release.apk
```

## Responsabilidad

- Driver principal: Estudiante 1.
- Revisor cruzado: Estudiante 2.
