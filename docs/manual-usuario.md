# Manual de usuario v0.1.0

## Pasajero

1. Abre la aplicacion web.
2. Revisa las rutas disponibles.
3. Lee la recomendacion del sistema.
4. Elige la ruta con menor demora y menor ocupacion.

## Operador

1. Revisa la lista de rutas.
2. Identifica buses con retraso alto.
3. Atiende rutas con ocupacion alta.

## Version actual

La version `v0.1.0` contiene un prototipo del recomendador para validar la historia HU-01.
